# Walkthrough poster

[poster.pdf](poster.pdf) and [poster.png](poster.png) are a one-page, step-by-step tutorial for first-time users: what Cellpose does, how to set up this server, what to ask at each step, and what to check. The poster text and layout are covered by this repository's [license](../LICENSE); the logo and images keep their own terms.

| Content | Source | Terms |
| --- | --- | --- |
| Cellpose logo | [Cellpose repository](https://github.com/MouseLand/cellpose), `cellpose/logo/logo.png` | BSD-3-Clause |
| Nuclei images (U2OS cells, Hoechst stain) | Image set [BBBC039v1](https://bbbc.broadinstitute.org/BBBC039), Caicedo et al. 2018, available from the Broad Bioimage Benchmark Collection (Ljosa et al., *Nature Methods*, 2012) | CC0 |
| Outlines, counts, diameter, and the clarification request | Masks and answers that the agent produced through this server in the [October 2026 pilot](../evaluation/pilot-2026-10/README.md), tasks t01, t02, t09, t10, and t11 | This repository |

The outlines are drawn from the saved label masks; the counts are the number of labels in each mask.
